## 直接体验（最简单）
解压后，用桌面 Chrome / Edge 打开根目录的 **Highway-Heroes-Pacific.html**。
这是约 26.6 MB 的单文件单机版，已内嵌人物生成代码、车衣、音乐和音效，不需要安装 npm 依赖或企业登录。
如果浏览器限制本地文件的音频或图形资源，请使用下面的本地服务方式。
首次进入时点击菜单启动声音；需要开启浏览器硬件加速并支持 WebGL2。

## 稳定的本地服务方式
已安装 Node.js 的 Windows 电脑：双击 **START-GAME.cmd**。
会打开 http://127.0.0.1:5189/offline.html。保持启动窗口开着，关闭窗口即停止。
脚本只监听本机地址，不向局域网公开。
端口冲突时在终端设置 HIGHWAY_PORT 为其他端口，再运行 node serve.mjs。

## 这次改了什么
1. 渲染：PBR 光照、金属／橡胶／皮革材质、柔和阴影、ACES 色调映射、正常 sRGB 输出和远景雾；去掉漫画描边与霓虹轮廓。
2. 摩托：重新搭建三种分部件模型，区别复古街车、越野车和全包围跑车；独立轮组、刹车盘、辐条、车架、发动机散热片、排气、座垫、灯具、后视镜；车轮随速度转动，车衣只影响漆面件。
3. 人物：新版原创参数化头部和全身轮廓，兼容原 17 个关节的控制名称。重做肩颈、胸腰胯、上臂前臂、大腿小腿、耳廓、手掌与五指、鞋型及衣服细节。10 项体型参数改变实际几何与关节位置；骑乘时按体型调整座位和手脚关节约束。基础脸型及五官数值用于新头部表面，不再使用旧球形头部 morph 网格。
4. 地图：海岸城区／荒漠公路／高山隘口。重建道路标线、护栏、路灯、路牌、房屋窗框与屋顶设备、棕榈／松树、停车区、山体和路基地形。
5. 道具：立体氮气瓶、护甲板、导弹、地雷替换发光图集，发射体也使用同套部件；轮胎障碍做成中空轮胎，油桶添加箍与桶盖细节。
6. UI：按游戏 UI 与前端设计技能统一流程和层级，海军蓝底／洋红主操作／青色交互信号，主菜单收起成绩榜，保留比赛中央视野。
7. 修复视觉相关问题：路边实例容量越界、道路 UV 重复跳变、重复路肩、雪雨始终隐藏、高 DPI 选车台反复 resize，以及部分纹理清理问题。

## 源码开发
在 frontend 目录打开终端：
```sh
npm ci
npm run dev
```
打开终端显示的地址后，在地址末尾加 /offline.html 进行本地单机开发。
- npm run check：类型检查、46 项测试和正式构建。
- npm run build:portable：重新构建网页和根目录的单文件版。
- 模型结构：src/entities/DetailedMotorcycle.ts。
- 全身人物：src/entities/CharacterBody.ts；头部：src/entities/CharacterGeometry.ts。
- 角色数据：src/settings/CharacterStore.ts；编辑器：src/ui/CharacterEditor.ts。
- 关节约束：src/entities/RiderIK.ts；角色制作与限制：docs/CHARACTER-STUDIO.md。
- 地图部件：src/render/Environment.ts。
- 统一材质与光照：src/render/Art.ts。
- 本地检查工具：打开 /offline.html?artReview=1，F2 显示／隐藏相机、路段、试驾和性能面板。检查跳转可能影响当局成绩，不应用来跑正式记录。

## 美术精度说明
这是 GTA5 所代表的写实都市／公路方向的浏览器级原创重制，不是 GTA5 原版资产或同等级 AAA 精度。
新车和场景是可编辑的程序化 Three.js 网格，**不是对原三辆 CAD GLB 做人工拓扑重建，也没有另外导出新的 GLB 文件**。
人物已替换为新的程序化轮廓网格，而非旧的球形五官与块状躯体，但仍是轻量化人物。尚无扫描皮肤、真实毛发、肌肉蒙皮、动态布料或 GTA 原生遗传系统。若后续需要影视级近景，需继续用 Blender / DCC 制作雕刻、拓扑、UV、皮肤和布料纹理。
线路形状、碰撞判定尺寸和基本计分沿用原版；后续迭代已修改导弹选敌、天气时序和冲线结算，不能再概括为“所有规则未变”。后端联网功能、实体手柄和真实手机性能未在本次实机检查中验证。
