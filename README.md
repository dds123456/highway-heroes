# 极速公路 HIGHWAY HEROES

卡通渲染开放式高速公路摩托竞速游戏。技术栈固定为 Three.js r168 + Vite + TypeScript + ES Modules，全部几何体、纹理、音频均由代码在运行时程序化生成，不依赖任何外部素材文件。

在线地址：https://highway-heroes-peach.vercel.app
GitHub 仓库：https://github.com/dds123456/highway-heroes

## 启动

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可游玩，无需额外环境变量或全局工具。

也可以直接双击 `start_game.bat`：脚本会自动安装依赖、选择空闲端口、启动开发服务器并打开浏览器。

需要发布到 GitHub 和 Vercel 时，双击 `deploy.bat`：脚本会引导 GitHub 与 Vercel 登录，然后自动创建仓库、推送代码并执行生产部署。

其他命令：

```bash
npm run build      # TypeScript 类型检查 + 生产构建
npm run preview    # 预览生产构建
npm run screenshot # Playwright 自动截图评审（dist 缺失时自动构建，并启动临时 preview server）
```

## 操作

- `W / ↑` 油门
- `S / ↓` 刹车
- `A / D` 转向
- `Space / X` 漂移（持续压弯积累氮气）
- `W + Q` 氮气冲刺（氮气槽满时同时按住）
- `Esc` 暂停
- 手柄：左摇杆转向、RT 油门、LT 刹车、A 漂移、Y 氮气

## 架构

```text
src/
  core/        Game 主循环、事件总线、输入、全局常量与配色板
  math/        闭合 CatmullRom 赛道采样、进度/曲率/坡度查询
  render/      WebGL2 后处理渲染器、Toon 材质、外扩描边、天空、道路、环境、粒子
  entities/    摩托实体、骑手程序化动画、街机物理
  ai/          AI 车手寻路、性格与橡皮筋系统
  race/        倒计时、圈数、检查点、排名与结算
  ui/          HUD、标题/暂停/结算屏幕（锚点响应式布局）
  audio/       Web Audio 程序化引擎声、风噪、漂移与音效
  types/       全局调试接口类型
```

## 渲染管线

1. 阶梯量化卡通漫反射：所有非真实感材质共享 4 档 `NearestFilter` 梯度贴图，阴影边界硬切。
2. 双层描边：几何体外壳沿法线外扩（屏幕空间恒定宽度）负责大轮廓，MRT 法线/深度 Sobel 后处理负责内部结构线，两条线做阈值融合。
3. Fresnel 边缘光：车辆与骑手材质叠加玫红/青蓝轮廓光，高速时与远景分离。
4. Matcap 分段硬边高光：运行时 Canvas 生成同心硬边 Matcap，采样后量化成 3 段。
5. 卡通天空：穹顶顶点渐变 + 7 段水平色带 + 硬边太阳，云层为带黑色描边的 Canvas 卡通云 Sprite。

道路为闭合 CatmullRom 样条，按 24 个区块流式显隐；护栏、路灯、树木、灌木、交通锥、广告牌与城市场景楼群全部使用 `InstancedMesh`；远山、远景使用 LOD 层级与粗模实例。赛道沿途布置发光加速板与可碰撞的路障/轮胎堆/施工桶，撞上会减速并触发撞击特效。

天气系统会按时间自动轮换晴天、下雨、雷暴、下雪：雨雪粒子围绕相机生成，雷暴伴随闪电白闪与延迟雷声，不同天气还会改变程序化环境音。车辆最高速度约 340 km/h，加速曲线设计为约 30 秒渐进达到极速，速度越高加速越慢；松开油门后风阻会明显拖慢车速。
