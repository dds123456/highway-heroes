# GitHub 公开单机版

日期：2026-09-09。此副本来自 Pacific 人物自然化 V2，经用户确认，仅发布单机游戏与配套素材/文档。

## 包含

- frontend 下的完整单机源码、测试、构建脚本和静态素材。
- 独立 HTML、启动脚本、README、docs 和实机截图。
- 本地人物、设置、成绩与幽灵数据功能；无需账号。

## 排除

- 企业登录脚本、内部接口请求、平台用户菜单和相关类型/样式。
- backend、平台专用部署配置、真实环境变量、数据库、依赖目录、缓存和日志。

index.html 和 offline.html 均为单机入口。net.ts 仅保留兼容空适配器，不请求在线榜单、不上传成绩。原私人工作副本及原 GitHub main 历史不覆盖。

docs 内关于“原平台入口／后端保留”的文字属于本地完整版本的历史记录，不适用于此公开副本；以本页公开范围为准。素材分组清单不是完整授权证明，保留素材的分发权仍需项目所有者核对。

公开版在隔离企业集成后重新运行类型检查、测试和单文件构建；实际结果以发布合并请求说明为准。不自动部署公网游戏或合并 main。
