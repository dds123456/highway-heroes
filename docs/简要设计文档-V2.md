## 1. 一句话概述

《极速公路》是一款 3D 卡通渲染街机摩托竞速网页游戏：玩家驾驶摩托在无限闭合高速公路上跑 3 圈，通过油门、刹车、漂移、氮气与加速板争夺名次；所有网格、纹理、音频均由代码生成，零外部素材。

## 3. 玩法摘要

- 闭合 CatmullRom 公路包含直道、S 弯、发卡弯、上下坡与跳台。
- `W/↑` 油门、`S/↓` 刹车、`A/D` 转向、`Space` 漂移、氮气满后 `W+Q` 冲刺。
- 漂移积累氮气能量；加速板提供瞬时提速与氮气补充。
- 撞上轮胎堆、施工桶、路障会明显减速并被弹开。
- 3 名 AI 车手分属激进型、稳定型、飘忽型，带轻微橡皮筋与避让。
- 天气系统会改变画面氛围并切换环境音。

## 4. 成长与运营

- 当前为单局街机竞速，无局外养成；结算展示名次、总用时与单圈成绩。
- 支持标题/暂停/结算三屏流程，`Esc` 暂停，结算可立即再来一局。

## 6. 技术要点

**性能硬指标**
- Retina（DPR≤2）稳定 60fps；掉帧时自动降 DPR 至 1.0。
- 道路/环境按 24 区块流式显隐，远离相机区块不渲染。
- 树木、灌木、护栏、路灯、楼群、远山全部使用 `InstancedMesh`。
- 粒子使用单 `Points` 池，雨/雪各自独立点云。

**架构手段**
- 闭合赛道采样 + 曲率/坡度查询，车辆沿 `progress + lateral` 行驶。
- 卡通渲染管线：4 档梯度图 + 外扩描边 + MRT 法线/深度 Sobel。
- 天气系统：雨/雪粒子围绕相机，雷暴带闪电白闪与延迟雷声。
- 截图测试：`npm run screenshot` 用 Playwright 自动生成多机位与天气截图。

**构建与发布**
- `npm install` → `npm run dev` 即玩。
- `start_game.bat` 双击启动；`deploy.bat` 一键 GitHub + Vercel 发布。
