> 版本：V2.0 · 重写日期：2026-08-16 · 状态：**设计稿（已对齐当前实现，待逐子系统评审）**
> 精度铁律：每个技术点**有名、有方法、有阈值、有陷阱**；性能是一等公民；视觉结论必须靠真实截图验证；质量**诚实分级**；数值分三类——`有 rationale` / `[PLACEHOLDER]` / `待验证`。

## 0. 精度标准：本 GDD 为什么这样写

| 范本要求 | 本作对应 |
|---|---|
| 技术栈 Vite + Three.js + TS + ESM，`npm i && npm run dev` 即玩 | 同左：Vite + Three.js r168 + TypeScript + ESM |
| 不使用任何外部素材 | 同左：网格程序化、纹理 Canvas2D/着色器噪声、音频 Web Audio 合成 |
| 目标硬件 + 60fps Retina | §1.3：MacBook M 系 + Chrome + Retina 60fps |
| 美术方向是核心（NPR，零 PBR） | §2：卡通竞速视觉是整篇文档的心脏 |
| 把最难系统当 3A 独立问题 | §3：把"无限公路 + 骑手动画 + 速度感"当 3A 独立问题 |
| 截图测试工具 + 视觉评审 | §13：`npm run screenshot` + 多机位评审 |
| 按可游玩里程碑交付 | §13.4：8 个里程碑 |
| 诚实记录质量 | §15：诚实质量记录 |

**Fun Hypothesis（一句话，地基）：** 好玩的核心是——**"在一条永远向前、弯道起伏可读的卡通高速公路上，用油门、刹车、漂移和氮气维持最高速，同时读线、躲障碍、吃加速板，把每一圈跑成有节奏的街机演出。"**

**Design Pillars（不可妥协）：**
1. **速度感可信**：FOV、风噪、路面颠簸、粒子、相机震动全部服务于"真的很快"；速度只是数字 = 失败。
2. **NPR 卡通统一**：阶梯光照 + 墨线 + 有限高饱和色板；任何 PBR 写实表面 = 美术方向失败。
3. **反馈要硬**：漂移、氮气、碰撞、拾取、天气都必须有明确视觉/音频/屏震反馈。
4. **性能是一等公民**：Retina 60fps；流式区块、实例化、自适应 DPR 是架构，不是优化尾巴。

## 1. 不可妥协的约束

### 1.1 品类 / 平台 / 目标用户 / 单局时长

| 项 | 取值 |
|---|---|
| 品类 | 3D 卡通渲染街机摩托竞速（网页） |
| 平台 | PC 浏览器（Chrome/Safari/Edge） |
| 目标用户 | 16–35 岁街机竞速与卡通美术爱好者 |
| 单局时长 | **3–6 分钟**（3 圈，含倒计时与结算） |

### 1.2 技术栈（硬性）

- Vite + Three.js r168 + TypeScript + ES Modules。
- 两条命令进入游戏：`npm install` → `npm run dev`。
- UI 用原生 DOM + CSS 卡通自绘，不引 UI 库。
- 构建配置在仓库内开箱即用，无额外环境变量。

### 1.3 零外部素材（硬性）

- 网格：全部程序化几何体；禁止 `.glb/.obj/.png` 模型。
- 纹理：Canvas2D 绘制或着色器噪声；禁止 HDRI/贴图/法线图。
- 音频：Web Audio 合成；禁止 `.mp3/.wav`。
- 截图仅用于评审/文档，由 `.vercelignore` 排除。

### 1.4 目标硬件与性能预算

| 指标 | 桌面 |
|---|---|
| 设备 | MacBook M 系 / 主流 x86 独显或核显 |
| 分辨率 | Retina（DPR 上限 2） |
| 帧率 | **稳定 60fps** |
| Draw Call | ≤ 200（含后处理） |
| 粒子 | 同屏活跃 ≤ 1500 |
| 首屏到可操作 | ≤ 5 秒（含首帧着色器编译） |

> 性能本身就是质量要求。画面再漂亮，只要卡顿，就是失败。

## 2. 美术方向——整个项目的核心

### 2.1 阶梯量化漫反射

- 4 档梯度图，`NearestFilter`，硬切换。
- 档位阈值建议 `[0.02, 0.48, 0.82]`，按实际截图调整。
- 陷阱：梯度图两端留安全边；`mag/minFilter` 必须同为 Nearest。
- 陷阱：主光与环境光过强会压垮中间档，`uSunColor` 锁在 `[0.9, 1.15]`。

### 2.2 双层描边

- 几何体外壳：复制网格沿法线外扩，`side = BackSide`，屏幕空间恒定宽度。
- 后处理内部线：MRT 法线 + 深度，Sobel 提取内部轮廓。
- 协同：外轮廓实、内部线细，合成用 `max` 而非 `add`，避免线条发胖。
- 陷阱：硬边几何体外扩成锯齿 → 使用平滑/合并法线。

### 2.3 Fresnel 边缘光

- `rim = pow(1 - dot(N, V), rimPower)`，`rimPower ≈ 3–4.5`。
- 主色取玫红/青蓝强调色，高速时让摩托从公路背景中清晰分离。

### 2.4 分段高光（Matcap）

- 运行时 Canvas 生成同心硬边 Matcap，采样后量化 3 段。
- 不用立方体贴图反射探针，不出现 PBR 镜面。

### 2.5 天空与大气

- 穹顶顶点渐变 + 7 段水平色带 + 硬边太阳。
- 卡通云 Sprite 带黑色轮廓，缓慢漂移。
- 天气：雨点/雪花点云、雷暴白闪、叠加色层。

### 2.6 统一色板

| 类别 | 色值 |
|---|---|
| 墨线 | `#14141c` |
| 玩家 | 红 `#ff4d5e` + 黄 `#ffd23f` |
| AI | 蓝/绿/紫 |
| 天空 | 蓝 `#3d7df0` → 地平线暖黄 |
| 引导带 | 橙 `#ff8a3d` |
| 边缘光 | 玫红 `#ff4fa3` / 青 `#4ff5e3` |

### 2.7 美术失败判据

- 任何 PBR 模糊高光 → 失败。
- 描边近处粗成黑块、远处消失 → 失败。
- 高速时主体融进背景 → 失败。
- 天气层与场景色板割裂 → 失败。

## 3. 无限公路系统——把它当成 3A 级独立问题

> 范本把"水面"列为最难系统；本作对应物是**无限闭合公路 + 道路环境流式加载**。

### 3.1 赛道

- 22 个控制点生成闭合 `CatmullRomCurve3`，全长约 3.7km。
- 含直道、S 弯、发卡弯、上坡下坡、两处跳台。
- 2600 个采样点提供 `frameAt / curvatureAt / slopeAt / nearestProgress`。

### 3.2 道路几何

- 沥青、左右路肩、三条车道线、发光引导带。
- 路面顶点加微噪声，模拟轻微颠簸。
- 24 个区块流式显隐：只渲染玩家前后 620m 内的区块。

### 3.3 环境

- 城市区块：程序化楼群 + 窗格纹理。
- 森林区块：树木 + 灌木高密度实例。
- 全环：护栏、路灯、交通锥、广告牌、远山、地形。

### 3.4 失败信号

- 区块拼接可见缝隙 / LOD 跳变明显 / 重复感过强 → 失败。

## 4. 摩托物理与操控

- 车辆状态：`progress + lateral + speed + lean + pitch + verticalSpeed`。
- 转向随速度衰减：低速灵活、高速柔和。
- 漂移：高速大转向触发，积累氮气能量，完美漂移给加速奖励。
- 氮气：满槽后 `W+Q` 释放，`boostTimer = 2.4s`，最高速临时提升。
- 跳台：坡度检测 + 高速触发腾空，落地按冲击力缓冲下蹲。
- 障碍碰撞：速度保留 25%，横向弹开，碰撞冷却 1.5s。
- 加速曲线：`accel = 6.8 × (1 - v/V)^0.42`，约 30s 到 340 km/h。
- 风阻：加速时低阻力；松油门滑行时额外阻力明显拖慢。

**陷阱**：`dt` 必须 clamp ≤ 0.05，否则跳台/碰撞会穿模。

## 5. 骑手动画系统

| 状态 | 表现 | 驱动 |
|---|---|---|
| 待机 | 呼吸起伏 + 路面颠簸 | 正弦 |
| 压弯 | 身体向弯内倾斜 | lean |
| 加速/刹车 | 重心前移/后仰 | pitch |
| 漂移 | 压低车身 | drift |
| 腾空 | 收腿前倾 | airborne |
| 落地 | 膝盖缓冲下蹲 | impact |
| 冲线 | 举手庆祝 | finishTime |

> 失败信号：骑手看起来像"站桩道具" → 该子系统判失败。

## 6. AI 车手

| 性格 | 特点 |
|---|---|
| 激进型 | 走线大胆、频繁尝试超车、易失误 |
| 稳定型 | 走线标准、失误少、速度均衡 |
| 飘忽型 | 时快时慢、难以预判 |

- 前瞻采样弯道曲率，提前转向。
- 轻度橡皮筋：与玩家差距过大时微调速度。
- 车车间避让；随机失误给玩家超车机会。

## 7. 比赛框架

- 4 台摩托，3 圈，倒计时 3 秒起跑。
- 8 个检查门记录分段进度。
- 排名 = `圈数 × 赛道长 + 当前进度`。
- 冲线记录单圈/总用时，结算展示名次。

## 8. 天气与赛道道具

### 8.1 天气

| 模式 | 粒子 | 表现 | 音频 |
|---|---|---|---|
| 晴天 | 无 | 默认 | 引擎/风噪 |
| 下雨 | 雨点 900 | 蓝色叠加层 | 雨声循环 |
| 雷暴 | 雨点 + 闪电 | 暗色叠加 + 白闪 | 雨声增强 + 延迟雷声 |
| 下雪 | 雪花 650 | 白色叠加层 | 轻风噪 |

### 8.2 加速板

- 12 块，间隔约 1/12 圈，横向交替。
- 命中：`speed + 14`、`boostTimer 2.4s`、氮气 +25%。
- 冷却：每块 2.6s，避免同一块反复触发。

### 8.3 障碍

- 14 组轮胎堆/施工桶/路障。
- 命中：速度 ×0.25、弹开 2.3m、冷却 1.5s、触发撞击特效。

## 9. 相机系统

- 弹簧阻尼追尾相机，FOV 随速度从 62° 扩到 85°。
- 碰撞/落地触发短时屏震。
- 倒计时与结算使用电影化环绕运镜。
- 调试机位：`chase / hood / side / orbit / far`。

---

## 10. HUD / UI

- 速度表、圈数、名次、分段计时、漂移能量槽、迷你地图。
- 标题/暂停/结算三屏，全部卡通自绘 CSS。
- 迷你地图绘制赛道样条与 4 台车实时位置。

---

## 11. 音频（Web Audio 合成）

- 引擎：双振荡器 + 低通，转速随油门/速度联动。
- 风噪：速度越高音量越大。
- 漂移/碰撞/拾取/倒计时/冲线：短促包络合成。
- 天气：雨声循环 + 雷声低频长包络。
- 陷阱：Web Audio 需用户手势后 `resume()`。

## 12. 性能架构

| 手段 | 用途 |
|---|---|
| InstancedMesh | 树木/灌木/护栏/路灯/楼群/远山 |
| 区块流式 | 道路与环境只渲染玩家前后 620m |
| MRT | 法线+深度一次出，供 Sobel |
| 自适应 DPR | `min(devicePixelRatio, 2)`，掉帧降档 |
| Points 池 | 烟尘/雨/雪共用单 draw call |
| 共享材质 | gradientMap/Matcap 单例 |
