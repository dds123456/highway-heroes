# 2026-09-09 男女车手、赛博头盔与导弹规则

> 本文保留男女车手／头盔阶段的更新记录，并补充当前人物自然化 V2 的规则边界。核对日期：2026-09-09。[目录](README.md) · [GDD](GDD-游戏设计文档-Pacific.md)

- 角色工作室每个分类顶部都有「男车手 / 女车手」。选择改变肩腰胯、颈部和头部基础比例，保留当前滑杆、配色、服装等参数，不改变速度或碰撞性能。保存后同步车库和比赛；旧存档默认男车手。
- 新 YX-01 全盔：哑光黑切面外壳、青色窄视窗灯带、下颌装甲、通风口、冠部导光线和红色尾灯。男女车手共用，随头身比例缩放。「头盔预览」可在工作室查看，比赛默认佩戴。
- 玩家和 AI 统一导弹选敌：前方最近的未完赛车手优先；没有前方目标时攻击后方最近者；没有有效目标则保留导弹。前后按环形道路最近有符号距离判定，支持起终点交界，不按排行榜名次判定；保留原有导弹飞行速度和最大航程。
- 本轮不增加第二份独立男女存档：切换性别保留同一套自定义参数，避免丢失编辑结果。

- 旧版成品保留，新压缩包和试玩 HTML 另存；未部署公网。

## 当前版本补充

女性面部、衣着轮廓和发型在本阶段之后继续重做，当前表现以 [人物自然化 V2](CHARACTER-NATURAL-V2.md) 为准。旧档 gender 缺省为 0，女车手为 1；修改不改变驾驶性能。

导弹速度 150 m/s、最大累计航程 700 m。选敌按环路最短有符号距离，不按名次；恰好同进度或半圈距离归前方。选敌没有射程过滤，因此有目标不等于一定能命中。发射后不重新选敌，已选目标完赛后不会命中该目标；没有有效目标时保留库存。

护盾持续 5 秒，当前只在导弹命中流程判断，不免疫地雷或普通障碍。导弹命中复用障碍减速，并受其冷却／腾空条件限制，不是扣血系统。

上文“新增 7 项”指本阶段增量，不能当成完整测试数；当前总计 46 项，结果和未验证平台见 [验证记录](VERIFICATION.md)。此次文档同步没有另存新游戏包或更新公网版本。
