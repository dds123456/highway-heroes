## 8. 配置规范

- 全局数值集中在 `src/core/constants.ts`。
- 后续建议迁入 `data/balance.json`，按 `global / vehicle / ai / track / items / weather / hud` 分区。
- 校验脚本：`npm run screenshot` 验证视觉；`getState()` 暴露进度/速度/名次/帧率供回归。
