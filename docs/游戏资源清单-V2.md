## 4. 动画状态机文档

> 骑手/车辆姿态作为代码动画契约，格式如下：

| 状态 | 触发 | 时长 | 备注 |
|---|---|---|---|
| 待机 | 起步/静止 | loop | 呼吸起伏 + 路面颠簸 |
| 压弯 | 转向输入 | loop | 骑手向弯内倾斜，车身 roll |
| 加速/刹车 | 油门/刹车 | 0.1–0.3s | 重心前移/后仰 |
| 漂移 | 高速 + 大转向 | loop | 车身侧滑 + 烟尘粒子 |
| 腾空 | 跳台高速离地 | 0.5–1.2s | 收腿、前倾、落地缓冲下蹲 |
| 冲线庆祝 | 比赛结束 | loop | 举手庆祝 + 车身摇摆 |

## 5. 资源管理规范

1. **命名**：`类型_编号_中文名_英文名`（如 `AI_03_飘忽型_Weaver`）。
2. **程序化资源集中**在 `src/render/`、`src/entities/` 构造函数，便于统一换肤。
3. **截图不入包**：`screenshots/` 仅作评审与文档，由 `.vercelignore` 排除。
4. **文案集中**：HUD 文案先内聚于 `src/ui/HUD.ts`，后续迁入 `data/text.json`。
5. **音频参数化**：频率/时长/音量集中在 `AudioEngine` 方法内，后续可抽 `audio/params.json`。
6. **UI 图标清单**：HUD 用 Canvas 自绘速度表/迷你地图，不使用 emoji 作为核心图标。
7. **打包白名单**：`.vercelignore` 排除 `node_modules`、`dist`、`.env.local`、`screenshots`。
8. **天气粒子预算**：雨 ≤ 900、雪 ≤ 650、闪电白闪用 DOM 叠加层。
9. **性能三档预算**：最小/标准/演出，按帧率自适应 DPR。
10. **版本盘点**：每次玩法调整同步更新本文档与 `游戏数据-V2.md`。
