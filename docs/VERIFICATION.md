## 范围与已知限制

- Vite 提示原平台 SSO 非模块脚本／公共 CSS 不参与打包；这些文件在 dist 中保留，原平台入口需原部署环境。
- 没有测试原平台账号登录、联网排行榜、后端部署、实体手柄、真实手机或长期压力运行。
- 单文件已通过 HTTP 独立资源验证；不同浏览器对 file:// 的限制可能不同，因此同时提供 START-GAME.cmd 本地服务方式。
- 新增模型为轻量、可编辑的程序化网格；人物近景细节和场景密度仍不等同于 GTA5 等 AAA 游戏资产。
- 没有新增导出的 GLB，也未部署至公网。
