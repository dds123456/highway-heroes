## 文档一致性约定

- 设计目标、当前实现、实测结果和后续建议分别写清，不用主观百分比代表完成度。
- 当前角色仍是程序化风格化人物；当前地图仍是闭合路线主题；没有新增 GLB 导出或公网部署。
- 源码路径若注明相对 `frontend/src/`，先加该前缀；素材清单的路径统一相对项目根目录。
- 历史阶段的 18／30／34／37／44 项测试数不改写成 46；最新汇总单独记录。截图按拍摄阶段使用。
- 文件名包含 Toon、Sprite、旧车型 ID 或旧 GLB 加载辅助代码，不一定代表当前运行时仍使用旧美术；要跟踪实际调用链。
- 第三方／用户包内素材保留不等于分发许可已经核实。素材 JSON 是分组来源说明，不是完整许可清单。
