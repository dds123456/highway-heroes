---

## 0. 设计原则（不可妥协）

1. **零外部素材**：网格、纹理、音频全部代码生成。
2. **卡通渲染是核心**：阶梯光照、双层描边、Fresnel、Matcap；任何 PBR 写实感即失败。
3. **速度感是第一体验**：FOV、风噪、粒子、震动都必须服务于"真的很快"。
4. **反馈要硬**：漂移、氮气、碰撞、拾取、天气必须有明确反馈。
5. **诚实质量分级**：每个子系统给出真实完成度。

---

## 1. 项目目标

- 上线一款可玩、可发布、可复盘的 3D 卡通街机摩托竞速网页游戏。
- 技术栈：Vite + Three.js r168 + TypeScript + ES Modules。
- 零素材约束：所有几何、纹理、音频程序化。
- 目标硬件：MacBook M 系 + Chrome + Retina 60fps。
- 单局：3 圈约 3–6 分钟，4 车同场竞速。

---

## 2. 产品亮点

1. **无限闭合公路**：直道、S 弯、发卡弯、上下坡、跳台，区块流式加载。
2. **NPR 卡通竞速**：4 档阶梯光照 + 双层描边 + Fresnel + Matcap。
3. **街机物理手感**：漂移蓄能、W+Q 氮气、跳台腾空、碰撞惩罚。
4. **天气演出**：雨、雪、雷暴自动轮换，带粒子与音效。
5. **赛道道具**：加速板 + 轮胎堆/施工桶/路障，形成读线决策。
6. **AI 差异化**：激进/稳定/飘忽三种性格，带橡皮筋与失误。

---

## 3. 目标用户

- 核心：16–35 岁街机竞速玩家。
- 泛用户：卡通美术爱好者、网页游戏玩家。
- 使用场景：PC 浏览器，Chrome 优先。

---

## 4. 核心循环

```text
开始比赛（倒计时 3 秒）
  → 竞速 3 圈（油门/刹车/转向/漂移）
  → 漂移积累氮气，W+Q 释放冲刺
  → 吃加速板 / 躲障碍 / 超 AI
  → 冲线结算（名次 + 单圈 + 总用时）
  → 再来一局
```

**健康目标**：AI 差距过大时轻微橡皮筋；障碍惩罚明显但可恢复；加速板节奏让玩家始终有短期目标。

## 5. 车辆信息

### 5.1 玩家摩托

| 属性 | 数值 | rationale |
|---|---|---|
| 最高速 | 340 km/h（94.44 m/s） | 街机极速爽点 |
| 加速到极速 | ≈30 秒 | 长加速创造追赶节奏 |
| 加速曲线 | `6.8 × (1 - v/V)^0.42` | 速度越高加速越慢 |
| 刹车 | 48 m/s² | 高速可读、可救线 |
| 滑行风阻 | `0.0009 × v²` | 松油门明显减速 |
| 漂移 | 高速大转向触发 | 蓄能 + 压弯 |
| 氮气 | 满槽后 W+Q 释放 | 主动策略资源 |

### 5.2 AI 车手

| 性格 | 风格 | 失误率 | 漂移倾向 |
|---|---|---|---|
| 激进型 | 走线大胆、常超车 | 中 | 高 |
| 稳定型 | 标准走线、失误少 | 低 | 低 |
| 飘忽型 | 时快时慢、难预判 | 高 | 高 |

## 8. 难度与平衡

- AI 橡皮筋：差距过大时微调速度，保持竞争但不保送。
- 障碍惩罚：明显但冷却后可恢复，避免一次撞毁整局。
- 加速板：横向交替布置，鼓励玩家主动走线。

## 10. 失败判据（评审用）

- 任何表面出现 PBR 写实高光 → 美术失败。
- 高速时主体融进背景 → 失败。
- 骑手动画僵硬如雕像 → 失败。
- 障碍惩罚无感或过重 → 数值失败。
- Retina 下帧率 < 60 → 性能失败。
